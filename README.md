# AIU Digital University

Интерактивный прототип единой платформы университетских услуг **Astana International University** по Screen Atlas.

Прототип покрывает ключевые экраны атласа: SSO-вход, выбор роли, кабинет студента/сотрудника, каталог услуг, заявки, общежитие, очередь HR, операторский контур, аналитику и администрирование. Все сведения демонстрационные.

## Возможности

- Вход через имитацию университетского SSO и выбор роли
- Кабинет заявителя: услуги, заявки, уведомления, профиль
- Поток общежития: кампания → заявление (3 шага) → размещение → начисления
- Очередь HR и реестр сотрудников
- Оператор общежития: обзор, очередь, фонд мест, размещения
- Администрирование: доступы, услуги, календарь, интеграции, импорт, состояние системы
- `/atlas` — каталог экранов с кодами из Screen Atlas (D01, C01, S01, O01, …)

## Дизайн-система

По атласу AIU Digital:

- Indigo `#393185`, gold `#D2AE6D`, canvas `#F6F5FA`
- Заголовки: Cormorant Garamond
- Интерфейс: Inter
- Боковое меню 232 px, карточки 12 px

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3847](http://localhost:3847).

Сборка production:

```bash
npm run build
npm start
```

## Как пользоваться

1. Нажмите **Войти через университетский SSO**
2. Выберите роль (студент, сотрудник, специалист HR, оператор, администратор)
3. Пройдите сценарии из меню или откройте `/atlas` для навигации по экранам

Реальный SSO, PostgreSQL и интеграции с кадровой/академической/финансовой ИС в этом срезе не подключены — только кликабельный UI с демо-данными.
